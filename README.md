## ❓ FAQ

### Does OCR work with scanned PDFs?
OCR is intended for image-based pages where regular text selection does not work.

### Is text recognition always accurate?
No. Image resolution, document quality, language, and layout affect OCR accuracy.

### Does this replace manual proofreading?
No. Review names, numbers, tables, and critical text after recognition.

## 🛠️ Troubleshooting

- Ensure the downloaded archive is named exactly **`WindowsPDFOCRTextExtractor.zip`**.
- Extract it before running **`WindowsPDFOCRTextExtractor.exe`**.

- Text looks incorrect: try a higher-resolution, correctly oriented scan.
- No text was detected: verify the selected pages contain readable text.
- Characters are garbled: check OCR language support and document quality.
- **Download returns 404:** The release has not yet been published or its asset is not named `WindowsPDFOCRTextExtractor.zip`.
- **Windows displays a warning:** Verify the publisher and file provenance before proceeding; never bypass security warnings blindly.
